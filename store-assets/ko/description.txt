LocalView로 Google이 사용하는 언어와 지역을 선택하세요. VPN이 필요 없고 위치도 바뀌지 않습니다.

- 표시 언어: Google 메뉴와 버튼의 언어.
- 검색 결과 언어: 한 언어로 작성된 페이지만 표시.
- 지역: 결과와 가격을 우선 표시할 국가.

Google 검색, 지도, 이미지, 뉴스, 쇼핑, 동영상, 도서, 항공편, 호텔에서 작동합니다.

- 저장한 선택: 조합을 저장하고 한 번 탭해 전환.
- 지도만: 서비스별로 개별 설정. 예를 들어 지도는 일본어, 나머지는 영어.
- 새로고침이나 깜빡임 없음: 페이지를 불러올 때 바로 적용됩니다.
- 표시 언어 78개, 검색 결과 언어 35개, 지역 245개.
- 인터페이스는 12개 언어를 지원하며 라이트/다크 테마를 따릅니다.

개인정보: LocalView는 데이터를 수집하지 않습니다. 계정도 분석도 없고 아무것도 전송하지 않습니다. Google 사이트에서만 작동합니다.

Google은 Google LLC의 상표입니다. LocalView는 Google과 제휴 관계가 없으며 Google의 보증을 받지 않았습니다.
