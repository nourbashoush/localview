다른 나라 사람들이 보는 그대로 Google을 보세요.

LocalView로 Google 표시 언어, 검색 결과 언어, 결과를 가져올 국가를 선택할 수 있습니다. 실제 위치는 그대로이며, 설정은 페이지를 불러오는 즉시 적용됩니다.

사용 방법
1. 도구 모음에서 LocalView 아이콘을 클릭하세요.
2. 표시 언어, 검색 결과 언어, 지역을 선택하세요.
3. 적용을 클릭하면 끝입니다.

기능
- 저장한 선택: 한 번 탭으로 조합을 전환.
- 지도만: 서비스별 개별 설정. 예를 들어 지도는 일본어, 검색은 영어로.
- 표시 언어 78개, 검색 결과 언어 35개, 지역 245개.
- 12개 언어 지원, 라이트/다크 모드.

개인정보: LocalView는 데이터를 수집하지 않으며 아무것도 전송하지 않습니다.

Google은 Google LLC의 상표입니다. LocalView는 Google과 제휴 관계가 없으며 Google의 보증을 받지 않았습니다.
